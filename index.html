03. Mathematical Logistic Regression

Logistic regression calculates a linear score and converts it into a probability between 0 and 1.

Linear Equation

z = b₀ + b₁x₁ + b₂x₂ + ... + bₙxₙ

Sigmoid Function

P(Y = 1 | X) = 1 / (1 + e−z)

Graph 4: Logistic Sigmoid Function

The curve converts the linear score into a probability. The dashed line marks the 50% threshold.

Decision Rule

  • Probability of 50% or more: predict class 1.
  • Probability below 50%: predict class 0.
